# AGENTS.md — Quy tắc dự án ERP Hùng

## Quy tắc báo cáo sau khi hoàn thành mỗi bước (Step Completion Report):
Mỗi khi hoàn thành một bước/công việc, BẮT BUỘC phải báo cáo kết quả tổng kết chi tiết phân chia làm 3 mục rõ ràng:

1. **BE (Backend) làm gì:**
   - Liệt kê chi tiết các Services, Entities, Controllers, API Endpoints, Validation Rules và Exception handling đã triển khai/cập nhật.
2. **FE (Frontend) làm gì:**
   - Liệt kê chi tiết Giao diện UI (pages/components), Helper Modules, Form validation và API Integrations.
3. **Test (Kiểm thử) làm gì:**
   - Báo cáo số lượng và danh sách Test Cases Backend (.NET xUnit) & Frontend (Node.js test runner), cùng kết quả thực thi PASSED/FAILED.
